Кнопки Button

Основной элемент взаимодействия. Поддерживаются три вида, три размера и состояния hover / active / focus.

Варианты

<button class="btn btn--primary btn--md">Primary</button> <button class="btn btn--secondary btn--md">Secondary</button> <button class="btn btn--primary btn--md" disabled>Disabled</button>

Размеры

<button class="btn btn--primary btn--sm">Small</button> <button class="btn btn--primary btn--md">Medium</button> <button class="btn btn--primary btn--lg">Large</button>

Secondary — все размеры

Карточки Card

Универсальный компонент карточки. Поддерживает три размера и модификатор без изображения.

Три размера с изображением

Small

Маленькая карточка

Компактный вариант для списков и боковых панелей.

5 мин назад
Medium

Средняя карточка

Стандартный размер для основного контента и галерей.

1 час назад
Large

Большая карточка

Крупный формат для featured-контента и главных материалов.

3 часа назад

Карточка без изображения

No Image

Карточка без изображения

Подходит для текстового контента, уведомлений и информационных блоков.

Навигационное меню Navbar

Адаптивная навигация. На десктопе — горизонтальная, на мобильных — гамбургер-меню. Пример показан вверху страницы.

Структура разметки

<nav class="navbar"> <div class="navbar__inner"> <a class="navbar__brand">Brand</a> <button class="navbar__toggle" id="nav-toggle"> <span></span><span></span><span></span> </button> <ul class="navbar__menu" id="nav-menu"> <li><a class="navbar__link navbar__link--active">Главная</a></li> <li><a class="navbar__link">О нас</a></li> </ul> </div> </nav>
