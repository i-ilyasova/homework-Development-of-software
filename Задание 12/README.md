# ShopReact

Учебное React-приложение интернет-магазина.  
Разработано в рамках курса «Разработка прототипов программных решений», ДЗ 12.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## Сборка

```bash
npm run build
npm run preview
```

## Стек

| Технология | Версия | Использование |
|---|---|---|
| React | 18 | Компоненты, хуки |
| React Router | 6 | Маршрутизация |
| Context API | — | Глобальное состояние |
| Fake Store API | — | Данные о товарах |
| Vite | 5 | Сборщик |

## Структура

```
src/
├── context/
│   └── AppContext.jsx      # Глобальное состояние (товары, тема, избранное)
├── pages/
│   ├── Home.jsx            # Главная страница
│   ├── List.jsx            # Каталог с поиском и фильтрами
│   ├── Details.jsx         # Страница товара
│   └── About.jsx           # О проекте
├── components/
│   ├── Navbar.jsx          # Навигация с NavLink
│   ├── ProductCard.jsx     # Карточка товара
│   ├── Spinner.jsx         # Индикатор загрузки
│   └── ErrorMessage.jsx    # Блок ошибки
├── styles/
│   └── main.css            # Стили + CSS custom properties для тем
├── App.jsx                 # Корневой компонент с Routes
└── main.jsx                # Точка входа
```

## Маршруты

| Путь | Компонент | Описание |
|---|---|---|
| `/` | `<Home />` | Главная с hero-блоком и фичами |
| `/list` | `<List />` | Каталог: поиск, фильтр по категории, сортировка |
| `/list/:id` | `<Details />` | Детали товара: описание, рейтинг, избранное |
| `/about` | `<About />` | Описание проекта и технологий |

## Функционал

- **Каталог товаров** — загрузка из Fake Store API, карточки с названием, описанием, ценой, рейтингом
- **Поиск** — фильтрация по названию в реальном времени
- **Фильтр по категории** — чипы для каждой категории
- **Сортировка** — по цене (↑/↓) и рейтингу
- **Детальная страница** — полное описание, изображение, рейтинг со звёздами
- **Избранное** — кнопка «Добавить в избранное» на странице товара и в карточке; список хранится в Context API
- **Кэш данных** — повторный переход в каталог не делает новый запрос
- **Тема** — светлая / тёмная, переключатель в навигации
- **Состояния загрузки и ошибок** — спиннер и блок с кнопкой «Попробовать снова»

## API

```
GET https://fakestoreapi.com/products        → список товаров
GET https://fakestoreapi.com/products/:id   → товар по ID
```
